# 跳跃高度配置指南 - 策划专用

## 🎮 概述

现在跳跃系统使用直观的**跳跃高度**参数替代复杂的跳跃力度设置，策划人员可以直接设置角色能跳多高，系统会自动计算对应的物理参数。

## 🚀 快速开始

### 方法一：实时调试（推荐新手）
1. **启动游戏**
2. **查看左上角调试面板**
3. **拖动"跳跃高度"滑块**（1-8单位）
4. **实时测试跳跃感觉**

### 方法二：配置文件（推荐正式调整）
1. **右键Project面板** → Create → SayBoom → Movement → Jump Height Config
2. **命名**：比如"玩家跳跃配置"
3. **调整参数**（见下方详细说明）
4. **应用到游戏**（见应用方法）

## 📊 参数详解

### 🎯 核心参数（策划重点关注）

#### **跳跃高度 (Jump Height)**
- **含义**：角色能跳多高（Unity单位）
- **范围**：1-8单位
- **推荐值**：
  - 轻松跳跃：2-3单位
  - 标准跳跃：3-4单位  
  - 高难度跳跃：4-5单位
  - 超级跳跃：5-8单位

#### **重力强度 (Gravity)**
- **含义**：下落速度，影响跳跃手感
- **范围**：10-50
- **效果**：
  - 低重力(10-20)：飘逸感，慢节奏
  - 中重力(20-30)：平衡感，标准节奏
  - 高重力(30-50)：紧迫感，快节奏

### ⚙️ 高级参数

#### **可变跳跃系数 (Variable Jump Multiplier)**
- **含义**：短按和长按跳跃的高度差
- **范围**：0.1-0.9
- **效果**：
  - 0.1：短按跳得很低，精确控制
  - 0.5：平衡的高度差异
  - 0.9：短按和长按差异很小

#### **土狼时间 (Coyote Time)**
- **含义**：离开平台后还能跳跃的容错时间
- **范围**：0-0.3秒
- **推荐**：0.1-0.15秒

#### **跳跃缓冲时间 (Jump Buffer Time)**
- **含义**：提前按跳跃键的容错时间
- **范围**：0-0.3秒
- **推荐**：0.1-0.15秒

## 📈 计算结果显示

配置文件会自动显示：
- **计算跳跃力度**：系统内部使用的物理参数
- **理论最大跳跃高度**：长按跳跃的高度
- **短按跳跃高度**：短按时的跳跃高度

## 🎯 应用方法

### 实时应用到MovementSystem
```csharp
// 在脚本中应用
JumpHeightConfig config = yourConfig;
MovementSystem movementSystem = FindObjectOfType<MovementSystem>();
config.ApplyToMovementSystem(movementSystem);
```

### 保存当前调试参数
```csharp
// 将当前游戏中的参数保存到配置
config.LoadFromMovementSystem(movementSystem);
```


## 🔧 调试技巧

### 实时调试信息
- **左上角面板**显示当前跳跃高度
- **策划调整参数**区域可实时修改
- **计算跳跃力**显示内部物理值

### 测试建议
1. **先调重力**：确定游戏整体节奏感
2. **再调高度**：确定角色跳跃能力
3. **最后微调**：土狼时间等细节参数

### 常见问题解决
- **跳跃过高**：降低跳跃高度值
- **跳跃过低**：提高跳跃高度值
- **下落太慢**：增加重力值
- **下落太快**：减少重力值
- **操作困难**：增加土狼时间和缓冲时间

## 🎯 物理公式说明

系统使用经典物理公式自动计算：
```
跳跃力度 = √(2 × 重力 × 跳跃高度)
```

策划只需关注直观的跳跃高度，系统自动处理复杂的物理计算！
